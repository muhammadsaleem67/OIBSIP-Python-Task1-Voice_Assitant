# Python Voice Assistant

A voice-controlled desktop assistant built with Python. This project scales from core speech-to-text functionality to advanced natural language understanding and third-party API integrations.

### Features
* **Core Voice Interactions:** Microphone input parsing and offline text-to-speech feedback using `pyttsx3`.
* **Task Automation:** Automated web searches, email dispatching via `smtplib`, and asynchronous background timers.
* **Live API Integrations:** Real-time weather updates and general knowledge Q&A.
* **Dynamic Configuration:** Custom voice command mapping via JSON configuration files.
